# T20 - Visual da Ficha

Módulo para Foundry VTT que melhora o visual da ficha de jogador do sistema **Tormenta20**, usando apenas CSS (sem scripts).

- Foundry VTT: 13 (verificado na 13.351)
- Tormenta20: 1.5.015

## Instalação

No Foundry, vá em **Add-on Modules > Install Module** e cole no campo **Manifest URL**:

```
https://github.com/fernandowrpg/t20-ficha-visual/releases/latest/download/module.json
```

Depois ative o módulo no mundo, em **Manage Modules**.

## Personalização

As cores ficam nas variáveis no início de `styles/ficha.css` (`--t20v-accent`, `--t20v-bg`, etc.).
